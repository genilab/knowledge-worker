# Plan

## Summary

Present the knowledge-base dashboard or a confirmed topic dashboard without
modifying the workspace.

## Description

Read `knowledge/INDEX.md` for `Show knowledge` and show its maintained topic
navigation. For `Show knowledge {topic}`, resolve the named topic and present
its information, ideas, references, and available source-material navigation.
State when a topic is missing or ambiguous; do not create or edit content.

## Script Requirements

- Accept `Show knowledge` and `Show knowledge {topic}`.
- Read the maintained knowledge index and the confirmed topic records.
- Present only verified local navigation and content.
- Do not modify the workspace.
